# FUTURE_FS_01 – Personal Portfolio Website

## Overview

This project is a modern full-stack personal portfolio website developed as part of the Future Skills Full Stack Web Development Track (FS-01).

The portfolio showcases:

* Personal profile
* Technical skills
* Projects
* Education
* Certifications
* Contact section
* Resume download option

## Tech Stack

### Frontend

* React.js
* Vite
* CSS3
* Framer Motion

### Backend

* Node.js
* Express.js

### Deployment

* Frontend: Vercel
* Source Control: GitHub

## Features

* Responsive design
* Smooth navigation
* Animated hero section
* Project showcase
* Certification section
* Contact form
* GitHub integration
* Resume download
